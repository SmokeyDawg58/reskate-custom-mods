# Native Throwdown integration audit and implementation

The supplied Game Modes bundle is revision `f3316c1`. Its referee and wire format implement ten modes. The current workspace already implements a separate native 1-Up coordinator, a native three-card Throwdowns page, private setup/HUD models, exact-build native flag placement, native start transitions, and stock solo cleanup. These working systems remain authoritative.

The imported implementation uses trainer telemetry and its own `0xD5`/version 9 relay messages. It has no supported public DLL registration API. ReSkate's runtime DLL and overlay DLL communicate through existing callbacks; their exports and the session protocol must remain unchanged. Registration will therefore be internal, with validated challenge definitions and adapters rather than speculative external module loading.

## Integration plan

1. Preserve the stock S.K.A.T.E., Spot Battle, Skate Jam, and current 1-Up entry paths and UI ownership.
2. Reuse the supplied rules/runtime for Spot Jam, Hall of Meat, Deathrace, Domination, Graffiti, Skate Tag, Infection, and Hide & Seek. Register the existing native S.K.A.T.E. and 1-Up as canonical implementations; do not add competing cards for their imported alternatives.
3. Generate additional native cards from a validated registry. Stable IDs, deterministic palettes, native artwork/fallbacks, and distinct adapters drive card creation and selection. Do not load images or generate art through an external service at runtime.
4. Present configuration, lifecycle state, scores, timers, standings and cancellation through existing native widget models. Do not compile or activate the supplied Game Modes overlay menu/HUD renderers.
5. Route only mode messages through the imported decoder. Preserve the current stock and 1-Up relay handling, exact solo pending-queue retirement, and native state cleanup.
6. Coordinate active-mode/input/marker ownership so incompatible challenges cannot run concurrently. Map changes and missing dependencies must cancel cleanly and report why.
7. Run rules/registry/lifecycle tests, build the supported DLL, then validate the real game flow. Report observed results separately from untested multiplayer behavior.

## Requirements retained from the earlier project

1-Up uses 1–6 players, 20-second turns by default, no rounds slider, no scoring circle, landed skating trick points without the multiplier, three 1/U/P penalties and last-player-standing elimination. Native game UI components and authored start/countdown animations remain the presentation foundation. The exact solo Throwdowns unlock fix must remain intact. The native in-match Throwdown Panel/Quit route is unfinished in the starting snapshot and remains required.

- Twelve registered definitions preserve the three stock challenges and current native 1-Up; eight adapters add Spot Jam, Hall of Meat, Deathrace, Domination, Graffiti, Skate Tag, Infection, and Hide & Seek. Imported legacy 1-Up/S.K.A.T.E. are not alternate implementations.

- New challenge scores, clocks, status, standings, intro/countdown and completed-match leaderboard use the game's existing widgets and authored style/model records. World objectives use projected native notice widgets driven by route/capture/tag/player coordinates. Placement instructions use the actual controls supplied by the mode runtime.

- The supplied ImGui Game Modes HUD/menu and Bone Cam HUD renderers are not compiled or activated. Shared snapshot/input helper types from `Overlay` are data/input contracts, not HUD renderers. Existing ReSkate chat, console, and unrelated tools are retained.
- Countdown, teleport, session marker, cancellation and map-change ownership are coordinated with 1-Up and stock native challenges. End/error paths release mode locks, placements and forced Hall of Meat state. Mode messages now use version 10 of the private `0xD5` protocol for per-racer clocks and explicit finish-line state. Upstream multiplayer protocol is 47 after the v2.0.3 update; the existing 1-Up wire format remains separate. No new public module-loading ABI is invented.
