Change
------
Exact confirmed completion of a stock solo activity retains a separate
UI cleanup request after client-state cleanup. Once the native Throwdowns
radial model exists, its exact IsPendingQueue boolean is set to false using
the game's typed model publication under its model write lock. This lets
the existing authored predicate and UI bindings update normally. Entitlement,
queue-state, rule restrictions and the predicate itself are preserved.
The request survives opening the wheel later, is acknowledged once, and is
cancelled by a new queue or level change. Quit requests, unrelated activities,
other players and multiplayer events do not authorize it.
