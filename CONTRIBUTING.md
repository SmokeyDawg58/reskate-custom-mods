# Contributing

Start with the current release and read its known issues before reporting a problem. Include the build name, map, host or guest role, what you did and what happened. A short recording or screenshot helps with visual issues; never post private settings, credentials or personal logs.

For code changes, follow docs/BUILD.md and run the relevant tests. Explain the behavior before and after the change. Preserve working HUD behavior, native menu cleanup and host/guest ownership rules. Keep unrelated changes separate.

Disclose substantial AI assistance in your contribution description. The project's existing AI assistance is credited in CONTRIBUTORS.md. Contributions remain subject to the repository's GPL-3.0 license.
