# Current asset pack: 1.0.6 for custom ReSkate 2.1.0

**[Download the complete mod folder](https://github.com/SmokeyDawg58/reskate-custom-mods/releases/download/v2.1.0-custom-20261017/SmokeyDawg58-ReSkate_Throwdown_Assets-1.0.6-For-2.1.0.zip)** or use [Full](https://github.com/SmokeyDawg58/reskate-custom-mods/releases/download/v2.1.0-custom-20261017/ReSkate-2.1.0-Custom-Full.zip). The complete player pack is also included in Full, so players do not need to build assets.

This release refreshes the 2.1.0 installation instructions. The 17 native payloads and two external WAVs are unchanged from complete Assets 1.0.6; existing users can keep that pack. Every PC still needs the matching custom 2.1.0 DLL and launcher. The recovery C cue is a small embedded runtime sound, with source in the overlay.

**[Asset authoring source](https://github.com/SmokeyDawg58/reskate-custom-mods/releases/download/v2.1.0-custom-20261017/ReSkate-Throwdown-Asset-Source-1.0.6.zip)** contains the complete 2,147-resource FBPROJECT, matching FBMOD, provided pink R.E.S.K.A.T.E. logo, transparent gate-compass artwork, selected quiet WAV inputs and source tools. See [the current export guide](../src/contrib/throwdown-flags/ASSET_PACK_1_0_6.md). Earlier recipes are historical stages.

[Author/export code](../src/contrib/throwdown-flags) and [artwork/audio inputs](../src/assets/throwdowns) are also browsable here. The native_assets.bin source archive is supplied on this release for runtime builds, with its SHA256. It remains outside the lean DLL.

Keep layout.toc, Win32 and initfs_win32 directly inside the mod folder. Enable one matching copy. The folder has Thunderstore-compatible metadata; this GitHub publication creates no Thunderstore listing. Studio SDK/converter binaries and original game files are not redistributed.
